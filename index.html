Частые вопросы

Где взять токен для входа? +
Зайди на dnevnik.mos.ru, открой DevTools (F12), перейди во вкладку Application -> Cookies, найди AUPD_TOKEN и скопируй его значение.
Это безопасно? +
Да. Все данные хранятся только на твоём компьютере. Приложение не отправляет твои личные данные третьим лицам.
Как работает ИИ-помощник? +
Приложение отправляет текст задания на защищённый сервер, который обращается к GigaChat. Твой токен и личные данные при этом не передаются.
Почему видео-темы могут тормозить? +
Видео-фоны требуют ресурсов GPU. Если у тебя слабый компьютер, мы рекомендуем использовать обычные статические темы.
